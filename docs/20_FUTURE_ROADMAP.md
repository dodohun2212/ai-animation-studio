# AI Animation Studio
# Future Roadmap

Version: 1.0

---

# 1. 목적

본 문서는

프로젝트의 향후 개발 계획을 정의한다.

MVP 완료 이후

추가할 기능을 정리한다.

---

# 2. 개발 원칙

새로운 기능은

기존 구조를 변경하지 않는다.

Workflow

Character

Style

Lore

Memory

구조를 유지하면서

확장한다.

# 3. Phase 1 (MVP)

목표

AI 기반 릴스 자동 제작

구성

- 주제 입력
- Story 생성
- Scene 생성
- 이미지 6장 생성
- CapCut Motion Prompt 생성
- 사용자 CapCut 작업
- FFmpeg 자동 병합
- 최종 MP4 생성

상태

개발 대상

# 18. 제외 기능

다음 기능은

현재 로드맵에 포함하지 않는다.

- CapCut 자동 제어
- CapCut UI 자동화
- 마우스 매크로
- 키보드 매크로
- 비공식 CapCut API

# 19. 장기 목표

AI Animation Studio를

대표 캐릭터와

고유한 Style DNA를 유지하면서

반복적으로 애니메이션 콘텐츠를 제작할 수 있는

콘텐츠 제작 플랫폼으로 발전시킨다.
