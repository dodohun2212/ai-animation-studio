[1-1. 장면별 이미지 구도 · 최우선]
$scene_composition

이 장면의 정적 이미지 구도에는 위 장면별 설정을 최우선으로 적용하십시오.
프로젝트의 전체 카메라 느낌은 공통 촬영 방향을 위한 보조 원칙이며, 위 장면별 설정과 충돌하면 장면별 설정을 따르십시오.
camera_motion은 이후 영상 생성용 움직임 정보이므로 한 장의 이미지에 이동 궤적이나 시간 경과를 억지로 표현하지 마십시오.

[2. 실제 첨부 Reference]
아래 번호는 API에 첨부되는 이미지 순서와 정확히 일치합니다.
$references

[3. 영상·장면 전체 분위기 Reference Asset]
$atmosphere_asset_metadata

위 Asset은 모든 장면의 공통 분위기, 색조, 조명, 공간 감각과 시각 방향에 참고하십시오.
장면 대본에 없는 인물·사물이나 글자를 분위기 Reference에서 그대로 복사하지 마십시오.

[4. 장면 참고 Asset]
$scene_reference_asset_metadata

각 Asset의 사용 목적과 현재 장면 대본이 맞을 때만 해당 Reference를 사용하십시오.
배경과 소품은 장면에 필요할 때만 배치하고, Style은 외형 복제가 아닌 시각 방향에 반영하십시오.

[5. 이미지 제작 설정]
$production_settings

[6. Reference 적용 규칙]
각 첨부 이미지의 Asset 대표 이름, 유형, 역할, 설명을 위 명세대로 해석하십시오.
유형이 character이고 대표 캐릭터 이름과 일치하는 Asset은 대표 캐릭터의 외형 기준입니다.
대표 캐릭터는 모든 장면에 등장시켜야 합니다.
서브 캐릭터는 현재 장면 대본에 등장하거나 행동상 필요한 경우에만 배치하십시오.
각 Character Asset의 대표 이름을 첨부 Reference의 Asset 대표 이름과 연결하십시오.
서로 다른 캐릭터의 얼굴, 복장과 Reference 묶음을 혼합하지 마십시오.
같은 Asset 이름의 여러 각도 이미지는 한 캐릭터의 동일한 외형 자료이며 서로 다른 인물로 만들지 마십시오.
서로 다른 Character Asset의 얼굴, 머리, 복장, 대표 색상과 고유 소품을 섞지 마십시오.
각 장면을 분석하여 실제로 필요한 Reference만 사용하십시오. 필요하지 않은 Reference는 무시하십시오.
Background와 Object는 장면 내용에 등장할 때만 사용하십시오.
Style Reference는 전체 이미지 스타일에 반영하십시오.
대사 스타일은 인물의 표정·자세·행동 연출에만 반영하고 대사를 화면 글자로 표시하지 마십시오.
전체 영상 길이와 장면 수는 현재 장면의 서사적 위치와 비중을 판단하는 데 사용하십시오.

[7. 출력 요구사항]
위 장면 정보와 제작 설정을 반영한 한 장의 완성된 장면 이미지를 생성하십시오.
분할 화면, 콜라주, 캐릭터 시트 또는 여러 장의 이미지처럼 구성하지 마십시오.
이미지 제작 설정에 지정된 화면 비율을 정확히 유지하십시오.
자막, 워터마크, UI와 의미 없는 글자를 제외하십시오.
